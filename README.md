## How I work


- **Product management and ownership:** turn customer problems into scope, priorities, roadmaps and acceptance criteria; coordinate stakeholders and carry decisions through release.
- **AI and application security:** build controls around model inputs, agent permissions, retrieval, authentication and transaction workflows. Test failure cases and make the limits explicit.
- **Go-to-market:** connect positioning, working demos, pricing, onboarding, documentation and customer feedback to the product itself.
- **Engineering:** TypeScript, Node.js, NestJS, Next.js, Flutter/Dart, Rust, Python, PostgreSQL, Redis and AWS.
